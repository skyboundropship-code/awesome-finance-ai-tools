# Contributing

This list is generated from [TradingAIHub](https://tradingaihub.com) and re-verified weekly (repo activity, archived status, official vs community).

To suggest a tool: use the [Submit a tool](../../issues/new?template=submit-tool.yml) issue form (or the form at https://tradingaihub.com/submit/, which opens it pre-filled), or open a PR. No GitHub account? Email hello@tradingaihub.com. Finance/trading-related MCP servers, agent skills and APIs only. Entries that go stale (12+ months without commits) or archived are flagged automatically.
