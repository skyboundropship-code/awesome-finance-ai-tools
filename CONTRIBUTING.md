# Contributing

This list is generated from [TradingAIHub](https://tradingaihub.com) and re-verified weekly (repo activity, archived status, official vs community). See the [verification methodology](https://tradingaihub.com/verification/).

## How to suggest a tool
- Use the [Submit a tool](../../issues/new?template=submit-tool.yml) issue form, or the form at https://tradingaihub.com/submit/ (it opens the same pre-filled issue), or open a PR.
- No GitHub account? Email hello@tradingaihub.com.

## Inclusion criteria
1. **Real repo or official docs** — a public, working source repository (or official vendor docs for hosted APIs). No dead links, placeholders or mirrors.
2. **Finance-relevant** — market data, trading, crypto, accounting, banking/payments or financial research. General-purpose tools don't qualify.
3. **Active** — a commit within the last 12 months and not archived. Stale or archived entries are flagged automatically.
4. **Licensed** — the repo has an open-source license, or it is an official vendor product with clear terms.
5. **Labelled** — marked **official** (published by the vendor/data provider) or **community** (third party).
6. **No scams** — no guaranteed-returns claims, pump schemes, wallet drainers, unaudited token sales or referral-only links.

## PR format
- One tool per PR, added to the matching section in alphabetical order.
- Line format: `- [Name](https://github.com/owner/repo) - Short description ending with a period. \`official\`|\`community\``
- PR title: `Add <Name>`. In the description, say what it does and how it relates to finance, and disclose any affiliation with the project.

Note: README.md is regenerated from TradingAIHub's data, so accepted entries are added to the source data as well.

## Review process and labels

- First team reply within 2 business days.
- New submissions are labelled `submission` automatically. We add `under-review` while we check them against the criteria above, and `needs-info` if we still need license, pricing, docs or a broker-access answer from you.
- Tools that can connect to or trade through a broker or exchange account are labelled `broker-access`.
- We will not merge a PR or close a submission as accepted until the review is done. A reply is not a promise that the tool will be listed.

Please do not paste API keys, credentials or other private data into issues or PRs. GitHub is public.

## Questions and ideas

Product questions and ideas that are not a tool submission belong in [Discussions](https://github.com/tradingaihub/awesome-finance-ai-tools/discussions). Small, well-scoped tasks are labelled `good-first-issue`.

## Pull requests

Use the pull request template. One tool per PR, as described above. README.md is generated from TradingAIHub's data, so a README-only edit will be overwritten on the next weekly run; accepted entries are added to the source data as well.

Nothing here is investment advice.
