# Contributing

This list is generated from [TradingAIHub](https://tradingaihub.com) and re-verified weekly (repo activity, archived status, official vs community).

To suggest a tool: open an issue or PR with the name, link, one-line description and category. Finance/trading-related MCP servers, agent skills and APIs only. Entries that go stale (12+ months without commits) or archived are flagged automatically.
